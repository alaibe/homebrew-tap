# alaibe/tap

```bash
brew install --cask alaibe/tap/statim
brew install --cask alaibe/tap/kestrel
brew install --cask alaibe/tap/grenier
```

[Statim](https://statim.laibe.cc/) for macOS, with its `statim` command on the
PATH.

[Kestrel](https://kestrel.laibe.cc/), the keyboard-first email client.

[Grenier](https://grenier.laibe.cc/)'s desktop app, which runs its own daemon,
with its `grenier` command on the PATH.

Each app's release workflow writes its cask whole, so change a cask there: a
change made only here is gone at the next release.
