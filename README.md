# alaibe/tap

```bash
brew install --cask alaibe/tap/statim
brew install --cask alaibe/tap/kestrel
```

[Statim](https://statim.laibe.cc/) for macOS, with its `statim` command on the
PATH. Each release of [alaibe/statim](https://github.com/alaibe/statim) updates
the cask.

[Kestrel](https://kestrel.laibe.cc/), the keyboard-first email client. Each
Kestrel release updates the cask.
